# v0.1 API Frontend Implementation Guide

This guide provides instructions on how to integrate the TB40 API v0.1 into a frontend application. It is inspired by the implementation patterns used in the [TB40 Frontend (React)](https://github.com/Yayasan-Bina-Insan-Mustaqbal/tb40-fe).

## 1. Configuration

Set your API Base URL in your frontend environment variables (e.g., `.env` or `config.js`):

```env
VITE_API_URL=https://your-api-domain.com
```

## 2. Assessment Flow

### Step A: Fetch Questions
Retrieve the 40 questions based on the assessment type (`tb40` for adults or `tb40anak` for children).

**Endpoint:** `GET /api/v0.1/:type/questions.json`

```javascript
const fetchQuestions = async (type = 'tb40') => {
  const response = await fetch(`${API_URL}/api/v0.1/${type}/questions.json`);
  const data = await response.json();
  return data.parts[type].questions;
};
```

### Step B: Submit for Calculation
Once the user has answered all 40 questions (scores 0-100), submit the data for processing.

**Endpoint:** `POST /api/v0.1/:type/calculation`

**Request Body Template:**
```json
{
  "parts": {
    "umum": {
      "nama": { "lengkap": "Budi Santoso", "panggilan": "Budi" },
      "lahir": { "tanggal": "2015-05-20" },
      "tanggal": "2026-06-14"
    },
    "tb40anak": [80, 90, 70, 100, ...] // Array of 40 scores
  }
}
```
*Note: The key for the scores array should match the assessment type (`tb40` or `tb40anak`).*

## 3. Handling the Response

The API returns a highly structured JSON object. Key sections to focus on:

### Presentation & Summaries
Use `parts.tb40.tb40Presentation` for pre-formatted summaries and titles.

```javascript
// Example: Displaying the personality summary
const summary = result.parts.tb40.tb40Presentation.kepribadian;
return (
  <div>
    <h3>{summary.title}</h3>
    <p>{summary.data}</p>
  </div>
);
```

### Visual personality Maps (SVG)
The API provides two SVG visualizations. These are returned as raw XML strings in the presentation object.

*   `pemetaan_tafsir_bakat.file`: SVG colored by raw score.
*   `pemetaan_tafsir_bakat_byRank.file`: SVG colored by rank.

**React Tip:** You can render these safely using `dangerouslySetInnerHTML`:
```jsx
<div dangerouslySetInnerHTML={{ __html: result.parts.tb40.tb40Presentation.pemetaan_tafsir_bakat.file }} />
```

### Ranked Traits
To show the "Top 5" or "Bottom 5" traits, use `parts.tb40.tb40ResultRanked["40"]`.

```javascript
const topTraits = result.parts.tb40.tb40ResultRanked["40"].slice(0, 5);
```

## 4. Error Handling

The API now uses a standardized JSON error format. Always check for the `error` field in the response.

```json
{
  "error": true,
  "status": 400,
  "message": "Invalid tb40anak data...",
  "timestamp": "2026-06-14T..."
}
```

## 5. Integration Patterns from `tb40-fe`

*   **State Management**: Use a local state or a store (like Zustand/Redux) to track the 40 scores before submission.
*   **Progressive Loading**: Since calculation includes SVG generation and template rendering, show a "Calculating..." spinner during the POST request.
*   **Print Support**: The generated SVGs are optimized for high-quality printing. Ensure your CSS `@media print` rules allow the SVG to scale correctly on the page.
