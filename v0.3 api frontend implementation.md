# v0.3 API Frontend Integration Guide

This guide explains how to implement the **v0.3 Adaptive Assessment & Persistence Engine** in frontend applications. Version 0.3 introduces PocketBase state persistence, automatic age detection, fast-track anonymous boundaries, debounced auto-saving with server timestamp confirmations, a 4-Tier progression flow, Observer Mode, qualitative emoji slider descriptors, and post-report contact enrichment.

---

## 1. Core Endpoints Overview

| Endpoint | Method | Description |
| :--- | :--- | :--- |
| `POST /api/v0.3/submissions` | `POST` | Initialize a new submission session (supports explicit type or age auto-detection via `birth_date`/`age`, observer mode, org/event IDs). |
| `GET /api/v0.3/submissions/:id` | `GET` | Fetch submission status, current step, and `halfway_report` (Continue URL target). |
| `POST /api/v0.3/submissions/:id/evaluate` | `POST` | Debounced interaction step save and evaluation turn. |
| `PATCH /api/v0.3/submissions/:id/profile` | `PATCH` | Update profile data (`subject_name`, `birth_date`, `age`, `is_observer`), unlocking Tier 3 for fast-track users. |
| `PATCH /api/v0.3/submissions/:id/contact` | `PATCH` | Post-report contact enrichment (`email`, `phone`). |
| `GET /api/v0.3/submissions/:id/share` | `GET` | Public view-only result payload (Share URL target). |
| `GET /api/v0.3/:type/schema` | `GET` | Retrieve dynamic tier questions schema (`?is_observer=true&subject_name=Ahmad`). |
| `GET /api/v0.3/events/:eventId/submissions` | `GET` | Event admin batch export of all submissions for an event. |

## 2. Assessment Version & Age Auto-Detection

When initializing a submission or updating a profile:
1. **Explicit Selection**: Pass `"type": "tb40"` (Adults) or `"type": "tb40anak"` (Children).
2. **Automatic Age Detection**: Pass `"birth_date"` (e.g., `"2015-05-10"`) or `"age"` (e.g., `11`).
   - **Age < 15 years old** → Automatically assigned `"tb40anak"` (Children Version).
   - **Age ≥ 15 years old** → Automatically assigned `"tb40"` (Adult Version).

## 3. Step-by-Step Integration Workflow

### Step A: Initialize Submission Session (Blind or Full)

#### Option 1: Blind Fast-Track Initialization (Anonymous)
```javascript
const response = await fetch('http://localhost:4040/api/v0.3/submissions', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    is_anonymous: true // User starts assessment blindly without entering profile data
  })
});
const data = await response.json();
// data: { id: "sub_abc123", type: "tb40", status: "incomplete", next_tier: "tier_1" }
```

#### Option 2: Full Profile Initialization (With Auto-Age Detection)
```javascript
const response = await fetch('http://localhost:4040/api/v0.3/submissions', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    is_anonymous: false,
    subject_name: 'Ahmad',
    birth_date: '2015-05-10', // Auto-detects tb40anak
    is_observer: true
  })
});
const data = await response.json();
// data: { id: "sub_xyz789", type: "tb40anak", determined_by: "age_detection", detected_age: 11 }
```

### Step B: Interactive 4-Tier Assessment Flow

#### **Tier 1: Social Energy (Allocation)**
Submit percentage allocation for Introvert and Extrovert (must sum to 100). Anonymous fast-track users can complete this freely.

```javascript
const res1 = await fetch(`http://localhost:4040/api/v0.3/submissions/${submissionId}/evaluate`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    sequence_number: 1,
    answers: { tier_1: { introvert: 70, extrovert: 30 } }
  })
});
const step1 = await res1.json();
// step1: { next_tier: "tier_2", halfway_report: { completion_percentage: 25, ... } }
```

#### **Tier 2: Talent Orientation (Forced Ranking)**
Submit ordered array `['karsa', 'cipta', 'rasa']`. Anonymous fast-track users can complete this freely.

```javascript
const res2 = await fetch(`http://localhost:4040/api/v0.3/submissions/${submissionId}/evaluate`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    sequence_number: 2,
    answers: { tier_2: ['karsa', 'cipta', 'rasa'] }
  })
});
// step2 returned payload:
```

### Step C: Unlocking Tier 3 (Profile Completion Boundary)

### Step D: Tier 3 Incremental Batch Progression & Final Report

#### **Tier 3: 18 Sub-Groups Deep Dive (6 Batches of 3 Questions)**
The 18 sub-group indicators are presented in 6 category parts (3 questions per part). Frontends can submit answers incrementally per batch.

At each batch step (Parts 1–5), the server returns:
- `current_part`: `1..6`
- `completion_percentage`: `58%`, `67%`, `75%`, `83%`, `92%`
- `questions`: The next 3 sub-group questions (using `range_slider` inputs).
- `halfway_report.preliminary_results`: Updated `panggilan`, `bahasa_hati`, `gaya_belajar`, and a **clean visual SVG chart without numerical score text labels**!

```javascript
// Example submitting Part 1 with Range Sliders (sub_1, sub_2, sub_3)
const res3_1 = await fetch(`http://localhost:4040/api/v0.3/submissions/${submissionId}/evaluate`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    sequence_number: 3,
    answers: { tier_3: { sub_1: 85, sub_2: 70, sub_3: 60 } } // Slider values 0-100
  })
});
const step3_1 = await res3_1.json();
// step3_1: {
//   next_tier: "tier_3",
//   current_part: 2,
//   total_parts: 6,
//   questions: [ { id: "sub_4", ... }, { id: "sub_5", ... }, { id: "sub_6", ... } ],
//   halfway_report: { completion_percentage: 58, preliminary_results: { svg: "<svg>...</svg>" } }
// }

// Submitting final Part 6 (sub_1 to sub_18 complete)
const res3_final = await fetch(`http://localhost:4040/api/v0.3/submissions/${submissionId}/evaluate`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    sequence_number: 8,
    answers: { tier_3: { sub_1: 85, sub_2: 70, ..., sub_18: 90 } }
  })
});
// finalReport returned payload upon 100% completion (Tier 3 adjusts default_scores of 40 pillars):
// {
//   status: "complete",
//   next_tier: "tier_4",
//   halfway_report: { completion_percentage: 100 },

//     panggilan: "Sang Pelaksana Tangguh & Tekun",
//     highest_bahasa_hati: "Pertolongan Nyata & Aksi Nyata (Acts of Service)",
//     highest_gaya_belajar: "Kinestetik & Eksperimen Langsung (Praktik)",
//     bahasa_hati: [ /* All 6 ranked Bahasa Hati */ ],

//     top_subgroups_18: [ /* 5 Best Sub-Groups of 18 */ ],

//     ranked_subgroups_18: [ /* Complete 18 Sub-Groups list */ ],

//     svg: "<svg>...</svg>", // Full chart with numerical score text labels
//     default_scores: [ /* 40 pillar calculated scores adjusted by Tier 3 */ ]
//   }

```

### Step E: Tier 4 Optional 40-Pillar Precision Mode (18 Sub-group Adaptive Rounds)

If the user opts-in to Precision Mode (`request_precision: true`), Tier 4 evaluates the 40 precision pillars in **18 rounds**, prioritized by the user's top sub-groups (`ranked_subgroups_18`):

1. **Sub-group Focused Rounds**: Each of the 18 rounds evaluates the 40 precision questions associated with the target sub-group topic for that round.
2. **Dynamic Round Titles**: Use the returned `part_title` (e.g. `"Evaluasi Presisi Bakat (Giat bekerja)"`) as the header title for the round card.
3. **Pre-filled Default Values**: Each returned question includes `default_value` initialized from the preliminary sub-group score.

```javascript
// Step 4: Submitting Tier 4 Precision Sliders (Round 1 of 18)
const res4_1 = await fetch(`http://localhost:4040/api/v0.3/submissions/${submissionId}/evaluate`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    sequence_number: 9,
    request_precision: true,
    answers: {
      tier_4: { p_4: 88, p_25: 72 } // Submitting pillars matching target subgroup
    }
  })
});
const step4_1 = await res4_1.json();
// step4_1: {
//   status: "incomplete",
//   next_tier: "tier_4",
//   current_part: 2,
//   total_parts: 18,
//   part_title: "Evaluasi Presisi Bakat (Berambisi)",
//   completed_pillars_count: 2,
//   total_pillars_count: 40,
//   questions: [ { id: "p_13", subgroup_no: "1", text: "...", default_value: 85 }, ... ],
//   halfway_report: { completion_percentage: 76 }
// }
```

## 4. Key Frontend Features & Recommendations

1. **Debounced Auto-Save & Server Timestamp Indicator**:
   - Use a 500ms–1000ms debounce strategy when calling `/submissions/:id/evaluate`.
   - Update your UI indicator with the returned `timestamp` to show *"Saved at HH:mm:ss"*.
2. **Qualitative Emojis & Slider Descriptors**:
   - Parse `range_labels` from `/schema` endpoints to render dynamic emojis and descriptive labels as the user moves the slider.
3. **Halfway Report Preview & Comprehensive Report Payload**:
   - Use `halfway_report` returned at every turn to show a completion progress bar and preview intermediate top traits.
   - **`julukan`**: Short category persona title (e.g. `'Tegas yang Cerdas'`).
   - **`panggilan`**: Full persona title (e.g. `'Sang Pemimpin yang Tegas yang Tekun'`).
   - **`highest_gaya_belajar_arab` & `highest_gaya_belajar_tempat`**: Displays Arabic learning style terminology (*Al Fuad*, *Al Bashar*, *As Sam'u*) and physical environment recommendations.
   - **`bakat_kekuatan` & `bakat_kelemahan`**: Explicit lists of top 5 strongest talent traits vs top 5 weakest talent traits to manage/delegate.
   - **`recommended_profesi` & `recommended_jurusan`**: Recommended careers and academic majors.
   - **`lalai_warnings` & `lebih_warnings`**: Character risk alerts with `solusi_perbaiki`.
