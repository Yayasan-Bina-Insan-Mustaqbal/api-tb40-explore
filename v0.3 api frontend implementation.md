# v0.3 API Frontend Integration Guide

This guide explains how to implement the **v0.3 Adaptive Assessment & Persistence Engine** in frontend applications. Version 0.3 introduces PocketBase state persistence, debounced auto-saving with server timestamp confirmations, a 4-Tier progression flow, Observer Mode, qualitative emoji slider descriptors, and post-report contact enrichment.

---

## 1. Core Endpoints Overview

| Endpoint | Method | Description |
| :--- | :--- | :--- |
| `POST /api/v0.3/submissions` | `POST` | Initialize a new submission session (supports fast-track, observer mode, org/event IDs). |
| `GET /api/v0.3/submissions/:id` | `GET` | Fetch submission status, current step, and `halfway_report` (Continue URL target). |
| `POST /api/v0.3/submissions/:id/evaluate` | `POST` | Debounced interaction step save and evaluation turn. |
| `PATCH /api/v0.3/submissions/:id/contact` | `PATCH` | Post-report contact enrichment (`email`, `phone`). |
| `GET /api/v0.3/submissions/:id/share` | `GET` | Public view-only result payload (Share URL target). |
| `GET /api/v0.3/:type/schema` | `GET` | Retrieve dynamic tier questions schema (`?is_observer=true&subject_name=Ahmad`). |
| `GET /api/v0.3/events/:eventId/submissions` | `GET` | Event admin batch export of all submissions for an event. |

## 2. Step-by-Step Integration Workflow

### Step A: Initialize Submission Session
When the user clicks "Start Assessment":

```javascript
const response = await fetch('http://localhost:4040/api/v0.3/submissions', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    type: 'tb40', // 'tb40' or 'tb40anak'
    is_anonymous: false, // true for fast-track mode
    is_observer: true, // true if observing someone else
    subject_name: 'Ahmad', // target person's name
    org_id: 'org_123', // optional
    event_id: 'event_456' // optional
  })
});

const data = await response.json();
// data: { id: "sub_abc123", timestamp: "...", status: "incomplete", saved: true }
// Save data.id to URL: e.g. /assessment/sub_abc123
```

### Step B: Interactive 4-Tier Assessment Flow

#### **Tier 1: Social Energy (Allocation)**
Submit percentage allocation for Introvert and Extrovert (must sum to 100).

```javascript
const res1 = await fetch(`http://localhost:4040/api/v0.3/submissions/${submissionId}/evaluate`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    sequence_number: 1,
    answers: {
      tier_1: { introvert: 70, extrovert: 30 }
    }
  })
});

const step1 = await res1.json();
// step1: { next_tier: "tier_2", halfway_report: { completion_percentage: 25, ... } }
```

#### **Tier 2: Talent Orientation (Forced Ranking)**
Submit an ordered array of `['karsa', 'cipta', 'rasa']`.

```javascript
const res2 = await fetch(`http://localhost:4040/api/v0.3/submissions/${submissionId}/evaluate`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    sequence_number: 2,
    answers: {
      tier_2: ['karsa', 'cipta', 'rasa']
    }
  })
});

const step2 = await res2.json();
// step2: { next_tier: "tier_3", halfway_report: { completion_percentage: 50, preliminary_results: ... } }
```

#### **Tier 3: 18 Sub-Groups Deep Dive (5-Point Likert Scale)**
Submit ratings from 1 (Sangat Tidak Setuju) to 5 (Sangat Setuju) for the 18 sub-group indicators.

```javascript
const res3 = await fetch(`http://localhost:4040/api/v0.3/submissions/${submissionId}/evaluate`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    sequence_number: 3,
    answers: {
      tier_3: { sub_1: 5, sub_2: 4, sub_3: 3, ... }
    }
  })
});

const step3 = await res3.json();
// step3: { status: "complete", result: { ranked_categories: [...], default_scores: [...] } }
```

### Step C: Post-Report Contact Enrichment
Once the report is displayed, allow users to optionally attach their contact info:

```javascript
await fetch(`http://localhost:4040/api/v0.3/submissions/${submissionId}/contact`, {
  method: 'PATCH',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: 'user@example.com',
    phone: '+6281234567890'
  })
});
```

## 3. Key Frontend Features & Recommendations

1. **Debounced Auto-Save & Server Timestamp Indicator**:
   - Use a 500ms–1000ms debounce strategy when calling `/submissions/:id/evaluate`.
   - Update your UI indicator with the returned `timestamp` to show *"Saved at HH:mm:ss"*.
2. **Qualitative Emojis & Slider Descriptors**:
   - Parse `range_labels` from `/schema` endpoints to render dynamic emojis and descriptive labels as the user moves the slider.
3. **Halfway Report Preview**:
   - Use `halfway_report` returned at every turn to show a completion progress bar and preview intermediate top traits.
