# v0.2 API Frontend Implementation Guide (Short Version)

This guide explains how to implement the short version assessment flow introduced in v0.2. This version uses an allocation and forced ranking approach to estimate scores for the 40 pillars, allowing for a rapid assessment process.

## 1. Core Concept: Stateless Scoring
The v0.2 API is **stateless**. The frontend stores the user's answers and sends them to the server at each step. The server evaluates the answers and tells you what to do next.

## 2. Implementation Flow

### Step A: Fetch the Schema (Optional but Recommended)
Retrieve the structure of the tiers and dimensions to build your UI dynamically.

**Endpoint:** `GET /api/v0.2/:type/schema`

```javascript
const schema = await fetch(`${API_URL}/api/v0.2/tb40/schema`).then(res => res.json());
// schema.tiers contains tier_1 (allocation) and tier_2 (forced_ranking)
```

### Step B: The Evaluation Loop
Your frontend should maintain an `answers` object. Call the `evaluate` endpoint whenever an answer is provided.

**Endpoint:** `POST /api/v0.2/:type/evaluate`

#### Phase 1: Social Energy (Tier 1 - Allocation)
Start with an empty answers object.

**Request:**
```json
{ "answers": {} }
```
**Response:**
```json
{
  "status": "incomplete",
  "next_tier": "tier_1",
  "questions": [...],
  "dimensions": [...]
}
```

#### Phase 2: Talent Orientation (Tier 2 - Forced Ranking)
Submit the percentage allocation for Introvert and Extrovert.

**Request:**
```json
{ "answers": { "tier_1": { "introvert": 70, "extrovert": 30 } } }
```
**Response:**
```json
{
  "status": "incomplete",
  "next_tier": "tier_2",
  "questions": [...],
  "dimensions": [...]
}
```

#### Phase 3: Final Result (Default Scores)
Submit the forced ranking array (ordered from most to least dominant) for Karsa, Cipta, and Rasa.

**Request:**
```json
{ 
  "answers": { 
    "tier_1": { "introvert": 70, "extrovert": 30 },
    "tier_2": ["karsa", "cipta", "rasa"]
  } 
}
```
**Response:**
```json
{
  "status": "complete",
  "result": {
    "ranked_categories": [
      { "id": "bekerja_keras", "score": 0.49 },
      ...
    ],
    "default_scores": [90, 75, 90, 60, ...] // 40 integers representing the default scores
  }
}
```

### Step C: Generate the Report
Once you receive the `default_scores` array (40 integers) from the `/evaluate` endpoint, you can pass them into the standard `/calculation` endpoint to get the final SVG and parsed report.

**Endpoint:** `POST /api/v0.1/:type/calculation`

**Request:**
```json
{
  "parts": {
    "umum": {
      "nama": { "lengkap": "Budi" },
      "lahir": { "tanggal": "2000-01-01" },
      "tanggal": "2026-06-24"
    },
    "tb40": [90, 75, 90, 60, ...] // the default_scores array
  }
}
```

## 3. Summary Table

| Tier | Type | Purpose | User Action |
| :--- | :--- | :--- | :--- |
| **Tier 1** | Allocation | Energi Sosial | Bagi 100% (e.g. Introvert 70%, Extrovert 30%) |
| **Tier 2** | Forced Ranking | Orientasi Bakat | Urutkan Karsa, Cipta, Rasa |
| **Result** | Default Scores | Kalkulasi 40 Pilar | Gunakan array 40 score ke /calculation |
