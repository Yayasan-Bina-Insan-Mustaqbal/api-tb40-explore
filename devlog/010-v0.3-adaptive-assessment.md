# Devlog 010: Adaptive Assessment & Persistence Engine (v0.3)
**Date:** 2026-07-22
**Status:** PocketBase Stateful Engine & Dynamic Scoring Integrated

## Changes
We have implemented **v0.3 (Adaptive Tiered Assessment & Persistence Engine)**.

### 1. Stateful PocketBase Integration
- Added PocketBase integration (`services/pocketbase.js`) with Docker Compose service container.
- Schema defined in `pocketbase/pb_schema.json` supporting `organizations`, `events`, and `submissions` with optimistic concurrency sequence checking (`sequence_number`).

### 2. Multi-Tier Adaptive Questions Engine
- **4-Tier Progression**:
  - **Tier 1**: Social Energy Allocation (Introvert vs Extrovert).
  - **Tier 2**: Talent Orientation Forced Ranking (Karsa, Cipta, Rasa).
  - **Tier 3**: 18 Sub-Group 5-point Likert Scale Deep-Dive (*Sangat Tidak Setuju* to *Sangat Setuju*).
  - **Tier 4**: Optional Precision Mode (Full 40 Pillars).
- Added `image_url` and `image_alt` stock image visual cards for every question/dimension.
- Added qualitative `range_labels` with expressive emojis (e.g. 🤫, 🌿, 🤝, 🎉, 🧠).

### 3. Personalization & Observer Mode
- Added **Observer Mode** (`is_observer: true` & `subject_name: "Ahmad"`).
- Dynamic template interpolation:
  - Self-assessment: Direct phrasing.
  - Observer-assessment: Third-person template with `{{name}}` replaced by target subject name.
  - Anonymous mode: Fallback to `"Kamu"` (`tb40anak`) or `"Anda"` (`tb40`).

### 4. Real-time Progress Auto-Save & Halfway Report
- Endpoints return `{ id, timestamp, saved: true, halfway_report }` on every interaction.
- `halfway_report` provides completion percentage, pending questions, and preliminary trait calculations with neutral prior imputation for missing tiers.

### 5. Post-Report Contact & Event Admin Export
- Added `PATCH /api/v0.3/submissions/:id/contact` for attaching `email` and `phone`.
- Added `GET /api/v0.3/events/:eventId/submissions` for event admin batch export.
- Hardened anonymous fast-track route with `fastTrackLimiter` (max 15/15min per IP).

## Verification
- Created unit and integration test suites in `__tests__/v0.3_evaluate.test.js` and `__tests__/v0.3_submissions.test.js`.
- All automated Jest test suites passing cleanly.
